# SASISOPA para proyectos nuevos

Descarga `SASISOPA-PROYECTO-NUEVO.zip` y extrae todo antes de abrir `SASISOPA/INSTALAR.bat`.

Incluye 18 plantillas PDF limpias y el programa 0.2.13. Inicia sin estación, personas ni inventario cargados. No incluye perfiles de las pruebas con TENEX.

El instalador guiado es para Windows 10/11 de 64 bits y necesita Internet para descargar sus componentes. No es un EXE autónomo. La integridad del ZIP, la extracción y las huellas de sus 59 archivos de aplicación fueron verificadas. La instalación real en Windows aún no fue ejecutada en este entorno Linux; el instalador realiza comprobaciones antes de activar el programa.

Los documentos generados requieren revisar los datos y el contenido técnico antes de su uso.
